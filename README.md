# Just Enough Mods

Instance-style mod pack manager for tModLoader 1.4.4 — like Prism Launcher instances, but inside the game.

- Several packs, each with its own frozen copies of mods; switch from the Workshop → Mod Packs menu.
- Multiple packs can be active at once (e.g. a client-side optimization pack + a friend's pack); on conflicts the newer mod version wins.
- The Mods menu shows only mods of the active packs; toggles there are saved into the packs.
- Export / import packs as `.zip` files.

---

Менеджер сборок для tModLoader 1.4.4 в духе инстансов Prism Launcher, но прямо в игре: несколько сборок, можно активировать несколько одновременно, в списке модов — только моды активных сборок, экспорт и импорт сборок в `.zip`.
